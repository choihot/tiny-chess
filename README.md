A deterministic chess engine in one Python file. `main.py` is an lzma-packed payload plus its unpacker, 4,073 bytes, and it plays the make.fun env at `MAKEFUN_ENV_URL`. A local practice trial scored Elo 1191.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
